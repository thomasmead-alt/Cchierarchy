Imports

Drop in two cost-centre hierarchy CSVs and the master list. Both level-column and parent/child formats are auto-detected.

Expected columns

Level columns

Level1, Level2, ... LevelN, Code, Name

Each row is a leaf cost centre; columns left-to-right are levels in the hierarchy.

Parent / Child

Code, Name, ParentCode

Adjacency list. Each row is a node with a pointer to its parent's code.

Master list

Code, Name, ResponsiblePerson, ProfitCentre

Validates codes/names, finds missing cost centres, drives recommendations by responsible person, and assigns each cost centre to a profit centre for project scoping.

Profit centre hierarchy

Level1...LevelN, Code, Name  or  Code, Name, ParentCode

Each top-level node becomes a Project. A project's scope is every cost centre whose master ProfitCentre falls anywhere under that top-level node.
